# Autonomous Robotic System for High-Precision Surface Measurement

This project develops an autonoumous robot scanning system capable of detecting incomplete scan regions on industrial componenets. A UR5 robotic arm equipped with an EinScan HX scanner captures surface data, while computer vision algorithms analyse scans to detect missing regions.
